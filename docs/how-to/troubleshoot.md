# Troubleshoot

> How-to · [Documentation](../../README.md#documentation)

Find why a check failed or didn't run.

| Symptom | Cause, what to do |
|---|---|
| Exit 2, "render-only Argo CD: ..." | The preview is down or refuses the token: `kubectl -n argocd-preview get pods`; the gitops-ci Secret `argocd-preview` holds the token |
| `InvalidSpecError` for an Application | Argo CD itself can't render it; the message says why (path, chart version, kustomize). Same error as production would show |
| "not up to date with its target" | Rebase or merge `main` into the branch; Forgejo also refuses to merge it |
| "has manifests that no entry point reaches" | A wrong `path` in an Application (several directories at once: often one typo), or a new folder needing an entry point or an `ignore` entry |
| "is generated by deploy-talos.py" (warning) | Change the cluster file and run `deploy-talos.py`, or keep the same versions in the cluster file so its next run writes the file unchanged |
| "N resource(s) without a known schema" (warning) | Their CRD isn't in the kubeconform catalog: not validated, not an error |
| "N more Application diff(s) left out" | The comment's size limit; the check step's log has the whole report |
| Leftover `gc-...` Applications in the preview | A run died before its cleanup; the next run deletes those older than 2 hours |
